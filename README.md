# GOHA POS for Windows

Official GOHA POS Windows installer and portable downloads. Application source code and platform credentials are not hosted in this repository.

- Platform: https://www.goha-ai.com
- Downloads: https://github.com/LoayKhafagy/goha-pos-releases/releases/latest

The application uses a licensed GOHA branch subscription, staff PINs and background synchronization.

Current builds are not digitally signed. A physical printer acceptance check is required for each branch setup.
